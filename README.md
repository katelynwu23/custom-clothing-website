# Custom Clothing Website

A full-stack web project for a small custom clothing business. 

## Current Features
- Responsive frontend
- Home, gallery, order, and about pages
- Flask routing
- Custom order form
- SQLite database storage

## In Progress
- Admin dashboard
- Authentication
- Security improvements

## Tech Stack
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## How to Run
1. Clone the repository:
    git clone git@github.com:katelynwu23/custom-clothing-website.git
2. Go into the project folder:
    cd custom-clothing-website
3. Create a virtual environment:
    python3 -m venv .venv
4. Activate the virtual environment:
    source .venv/bin/activate
5. Install Flask:
    pip install flask
6. Start the application:
    python app.py
7. Open the following URL in your browser:
    http://127.0.0.1:5000
